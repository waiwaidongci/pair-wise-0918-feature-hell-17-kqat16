# hxyfront-62010 潜水气瓶充填记录 —— 设备维护锁工作流

源提示词编号：5

在原有气瓶充填记录（待充填队列、混合气比例提示、检验过期提醒、完成签收、单瓶历史）基础上，
增加**充填台设备维护锁**：

- **进入维护（压缩机 / 充填泵）**
  - 未开始且与维护窗口重叠的工单：**自动改约到同设备最近可用时段**，改约结果绝不与该设备其他工单或维护窗口重叠；级联冲突会继续顺延。
  - 已开始充填的工单：**保留现场**（气瓶压力、目标压力、O₂/He 配比、操作员均不动），记录暂停时刻与**暂停前进度**。
- **结束维护**
  - 被暂停的工单**按暂停前进度恢复**，按实际时间记录暂停时长（本次/累计），预计完成时间顺延。
  - 维护若超时，排在"预计解锁点"的工单会被再次自动改约；恢复后排班整体刷新，冲突工单自动顺延。
- **改约规则**：客户改约满两次后锁定，后续改约一律**沿用首次确认信息快照**（客户、充填方式、O₂/He、目标压力、操作员）。
- **一致性**：设备状态由维护锁与工单实时派生；`findConsistencyIssues` 持续审计设备状态 / 工单历史 / 刷新后排班，页面审计面板实时展示。

## 演示操作

1. 对 **1号主压缩机（CP-01）** 启动维护锁（如 100 分钟）：
   - WO-1003（充填中）立即暂停并显示暂停前进度；
   - WO-1001 / WO-1002（未开始）自动改约到维护结束后的最近时段；
   - 时间轴上可看到维护窗口与各工单时段互不重叠。
2. 快进时钟或点击"维护结束"：WO-1003 按暂停前进度恢复、暂停时长被记录，后续冲突工单自动顺延。
3. WO-1005 已改约两次，再次手动改约时确认信息保持首次快照。
4. 审计面板始终显示"三方数据一致"。

页面同时保留：待充填队列筛选、空气/高氧/Trimix 混合气比例提示、检验过期/临期提醒、完成签收、单工单完整历史时间线，以及新工单的最近可用时段推荐。

## 技术栈

React 19 + Vite + TypeScript（无后端，状态持久化在 localStorage）

开发端口：62010

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62010
npm test           # 工作流不变量测试（改约不重叠 / 暂停恢复 / 两次锁定 / 三方一致）
npm run typecheck
npm run build
```
