# hxyfront-62010 潜水气瓶充填记录

潜水店气瓶充填前端系统：工单排班、混合气比例提示、气瓶检验过期提醒、充填签收与单瓶历史，
并在充填台上实现**设备维护锁**工作流。

## 设备维护锁规则

- **上锁（压缩机 / 充填泵进入维护）**
  - 未开始充填的工单自动改约到维护结束后的**最近可用时段**；维护窗口前能完成的工单不动；
  - 已开始充填的工单**保留现场**、状态转暂停，快照暂停时刻与当前压力；
  - 自动改约按工单开始时间顺序进行，候选时段必须避开维护窗口、同设备其它工单及暂停恢复段，
    **同一设备时段绝不重叠**（15 分钟排班网格 + 5 分钟缓冲）。
- **解锁（维护结束）**
  - 暂停工单结算暂停时长，按暂停前压力折算的剩余工作量从解锁时刻**恢复作业**；
  - 维护若超时，与实际窗口/恢复段冲突的未开始工单自动顺延，**超时顺延不计入客户改约次数**。
- **客户改约**
  - 客户发起改约满 **2 次**后，姓名与联系方式强制沿用**首次确认信息**快照，提交的新内容被忽略；
  - 维护自动改约、超时顺延不占用客户改约次数；
  - 客户指定时间被占用时，自动取该时间之后的最近可用时段。
- **一致性**：设备状态、工单历史（事件流）、审计日志与刷新后的排班看板由同一份状态派生，
  排班看板实时显示"同设备时段无重叠/重叠"校验结果。

## 技术栈

React 19 + Vite 7 + TypeScript，`useSyncExternalStore` 状态管理，localStorage 持久化。
纯领域逻辑位于 `src/domain.ts`，不依赖 UI。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62010
```

演示时钟固定从 2026-09-18 09:00 起，可用页头按钮推进 15/60 分钟模拟维护超时；
"重置演示数据"可还原初始场景。

## 测试

```bash
npm test              # tsc 编译 + node:test 领域规则单测（10 项）
npx tsc -p tsconfig.test.json && node scripts/e2e.js   # 上锁→改约→超时→解锁 全链路断言
```
